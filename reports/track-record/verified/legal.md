# Verified — leader's legal record (methodology v1.3)
Verifier: independent pass · snapshot 2026-10-18

**How this pass worked.**
- Every cited URL was re-opened on 2026-10-18.
- Supreme Court documents were read in full from supremedecisions.court.gov.il. They were fetched inside the built-in browser and decoded from UTF-16 or windows-1255.
- News pages were fetched with curl and their text extracted. Times of Israel pages return 403 to curl, so they were read in the built-in browser.
- icc-cpi.int was blocked again: curl returned 504 and the browser showed a Gcore "you have been blocked" page. A web.archive.org copy stopped at a Cloudflare check, which was not bypassed.
- A row is kept only if the source supports the exact claim. Quotes are copied from the source.
- "Not confirmed" rows use the §4.1 label: "Current status not confirmed — last confirmed: X on DATE".
- Presumption-of-innocence line: "yes" when the case is open, or when its last confirmed status was open.

**v1.3 rules applied to every leader (not only to the rows researchers proposed):**
- Only formally started proceedings count.
- A case is attributed only when a source ties it to the leader personally.
- Israeli, international and foreign proceedings are all included.
- Each case is its own row.
- "Final" is used only when a source uses that word.

This created new rows for Ben Gvir (Turkey ×2, two Israeli files from Supreme Court decisions) and for Liberman (Spain 2015), because the same sources that support existing rows for Netanyahu name them too.
